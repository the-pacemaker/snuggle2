# Agent Guidelines for this Workspace

## Git Configuration
Git is installed and configured on this system.
The repository's remote URL (origin) is already configured with the user's Personal Access Token for HTTPS authentication.
Agents can use standard Git commands (git add, git commit) to save progress locally, but MUST NOT upload/push code to the remote repository (GitHub) unless the user explicitly asks them to. No further authentication setup is required.
